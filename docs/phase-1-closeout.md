## Phase 2 implications

- **Accepted decision.** [ADR-001](decisions/ADR-001-phase-1-source-baseline.md) keeps PG16 stock, separated from the consumer, and the source receipt outside Bronze parity. The two-slot limit leaves room for one persistent slot and one temporary snapshot slot. Plan serial table onboarding first and verify slot reuse. Changing the slot budget requires measured justification.
- **Observed Phase 1 limits.** The source startup preflight requires an empty bridge and is tied to the Phase 1 Compose profile. Gate the actual empty bridge before starting PG16, then verify the Phase 2 overlay and peer boundaries before attaching the consumer. The source-gate harness asserts zero replication objects. Reuse its oracle, workload and fault controls on CDC runs and keep the full source regression on a clean source-only project. The earlier 1,536 MiB consumer design allowance and the 768+256 MiB source/runner caps together exceed the existing guest's 2 GiB before OS overhead. Measure a smaller Phase 2 budget and serialize runtime experiments. [Phase 2 runtime conventions](../backlog/phase-2.md#parallel-development-and-runtime-conventions)
- **Documented compatibility.** PostgreSQL 16 supports the pinned client's pgoutput protocol version. The pinned DuckPipe source creates a slot, creates/changes a publication and alters source replica identity. A disposable role and cleanup contract need testing before this can be a normal setup. The May CI artifact and its expected DuckLake format are known inputs. [Pinned-source and artifact review](experiments/EXP-010-phase-2-candidate-review.md)
- **Open research.** Remote TCP/SCRAM, snapshot/WAL overlap, inserts/updates/deletes, durable apply versus feedback, slot loss and same-slot restart, cross-table visibility and actual catalog format all need Phase 2 evidence. R01–R05, R13 and R16 stay open at full scope. R25's Phase 1 receipt result informs Phase 6. Operational write-back remains open. [Research register](research-questions.md#phase-1-source-evidence)

**Planning checks.** `make help check BASE=origin/main`, `make test-unit` (24 tests), `sh tests/repository-checks.sh` (five cases), integration shell syntax and the staged diff whitespace check passed. A local check matched all ten draft IDs, titles and dependencies to the registry and graph, confirmed their experiment IDs were unused and resolved relative links and headings in the changed Markdown.
